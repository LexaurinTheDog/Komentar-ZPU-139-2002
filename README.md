# Komentář k zákonu č. 139/2002 Sb., o pozemkových úpravách a pozemkových úřadech

Otevřený komentář k zákonu o pozemkových úpravách a pozemkových úřadech — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; účel a obvod pozemkových úprav, účastníci a sbor zástupců, soupis nároků, plán společných zařízení, návrh a jeho schválení, výměna vlastnických práv, náklady, úřední oprávnění k projektování a pozemkové úřady.

Konsolidované znění: dokument e-Sbírky `SB-2002-00139_2025-10-01`.
